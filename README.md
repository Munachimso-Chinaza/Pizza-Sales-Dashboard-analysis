## Overview
This project presents a complete data analytics pipeline for pizza sales. I used Python for data scraping and automation, MySQL for cleaning and organizing the data, and Tableau to build an interactive dashboard that delivers clear business insights.

## Technologies Used
- **Python**: Scraping, automation scripts, Pandas for initial processing
- **MySQL**: Database setup, data cleaning (handling missing values, duplicates), queries for aggregation
- **Tableau**: Professional dashboards with filters, calculated fields, and storytelling

## Project Workflow
1. Collected and automated pizza sales data using Python
2. Loaded raw data into MySQL and cleaned it thoroughly
3. Connected cleaned data to Tableau and created visualizations
4. Interpreted results to provide actionable recommendations

## Key Insights
- Identified top-selling pizza categories and individual items
- Discovered peak sales days and months for better staffing
- Found revenue trends and underperforming products

## How to Run the Project
1. Clone this repository
2. Install dependencies: `pip install -r requirements.txt`
3. Set up MySQL database and run the SQL scripts in the `sql/` folder
4. Run Python scripts in `src/` folder
5. Open the Tableau workbook (.twbx) in the `tableau/` folder
